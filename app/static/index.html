CLI & Piped Uploads

Park arbitrary files or pipe command outputs directly into KeepBoard RAM from your terminal:

1. Pipe Command Output (Logs / Dumps)
BASH
docker logs myapp | curl -F "file=@-;filename=app.log" http://localhost:8080/api/drop
2. Upload File with Tags & Title
CURL
curl -F "file=@data.csv" -F "title=Q4 Report" -F "tags=#finance" http://localhost:8080/api/drop
3. Direct Streaming Upload (No Multipart)
OCTET-STREAM
cat archive.tar.gz | curl -H "Content-Type: application/octet-stream" --data-binary @- http://localhost:8080/api/drop
